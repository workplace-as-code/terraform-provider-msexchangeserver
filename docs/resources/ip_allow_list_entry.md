# msexchangeserver_ip_allow_list_entry (Resource)

Manages an entry of the IP allow list of the connection filter agent: connections from the address or range are always accepted (`New-IPAllowListEntry`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `name` is the IP address (`192.0.2.10`), CIDR range (`192.0.2.0/24`) or address range (`192.0.2.1-192.0.2.9`), as `Get-IPAllowListEntry` shows it. Any change creates a new entry. An Edge Transport setting: on a Mailbox server, it needs the anti-spam agents and the Transport Hygiene role.

## Example Usage

```terraform
# Always accept the mail servers of a partner.
resource "msexchangeserver_ip_allow_list_entry" "partner" {
  name    = "192.0.2.0/24"
  comment = "Fabrikam mail servers"
}
```

### Optional

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

On an Edge Transport server, the account is a local administrator: Exchange has no role-based access control there. On a Mailbox server with the anti-spam agents installed, it needs the **Transport Hygiene** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) does not include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
