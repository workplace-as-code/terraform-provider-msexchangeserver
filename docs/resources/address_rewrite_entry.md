# msexchangeserver_address_rewrite_entry (Resource)

Manages an address rewrite entry, which rewrites the addresses of messages leaving or entering the organization (`New-AddressRewriteEntry`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `internal_address` and `external_address` are required to create an entry. Address rewriting runs on Edge Transport servers only.

## Example Usage

```terraform
# Mail of the subsidiary leaves with the addresses of the group.
resource "msexchangeserver_address_rewrite_entry" "subsidiary" {
  name             = "Fabrikam to Contoso"
  internal_address = "*.fabrikam.com"
  external_address = "contoso.com"
  outbound_only    = true
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `exception_list` (Set of String) Subdomains of a wildcard `internal_address` that are not rewritten.
- `external_address` (String) Address or domain the messages show outside.
- `internal_address` (String) Address or domain inside the organization, such as `contoso.com` or `*.contoso.com`.
- `outbound_only` (Boolean) Rewrite outgoing messages only. Required with a wildcard `internal_address`.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

On an Edge Transport server, the account is a local administrator: Exchange has no role-based access control there. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
