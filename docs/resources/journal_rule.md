# msexchangeserver_journal_rule (Resource)

Manages a journal rule, which sends a report of the matching messages to an archive (`New-JournalRule`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `journal_email_address` is required to create a rule. Journal rules need Exchange Enterprise client access licenses. Exchange sends the journal reports it cannot deliver to `msexchangeserver_transport_config.journaling_report_ndr_to`.

## Example Usage

```terraform
# Every message of the organization journaled to the archiving system.
resource "msexchangeserver_journal_rule" "all" {
  name                  = "Journal all mail"
  journal_email_address = "journal@archive.contoso.com"
  recipient             = ""
  scope                 = "Global"
  enabled               = true
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `enabled` (Boolean) Whether the rule is enabled. A rule created disabled never journals a message.
- `journal_email_address` (String) Address that receives the journal reports: a journaling mailbox or an archiving system.
- `recipient` (String) SMTP address of the mailbox, contact or group whose messages are journaled. `""` journals every recipient.
- `scope` (String) Messages the rule journals: all of them, internal ones or external ones. Valid values: `Global`, `Internal`, `External` (case-insensitive).

### Read-Only

- `id` (String) The object name (same as `name`).
