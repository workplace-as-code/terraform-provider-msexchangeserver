# msexchangeserver_outlook_anywhere (Resource)

Manages Outlook Anywhere (RPC over HTTP, the `/Rpc` virtual directory) of an Exchange server: its host names and authentication settings (`Set-OutlookAnywhere`). The object cannot be created: the resource adopts the existing one. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. `name` is the server name or FQDN, for the directory of the Default Web Site, or its identity as `Get-OutlookAnywhere` shows it, such as `EX01\Rpc (Default Web Site)`. Authentication settings are read from IIS: a plan fails when the server's IIS does not answer.

## Example Usage

```terraform
# One namespace for every client, Negotiate (Kerberos, then NTLM) everywhere.
resource "msexchangeserver_outlook_anywhere" "ex01" {
  name              = "EX01"
  internal_hostname = "mail.contoso.com"
  external_hostname = "mail.contoso.com"

  internal_client_authentication_method = "Negotiate"
  external_client_authentication_method = "Negotiate"
  iis_authentication_methods            = ["Basic", "Ntlm", "Negotiate"]
  internal_clients_require_ssl          = true
  external_clients_require_ssl          = true
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `external_client_authentication_method` (String) Authentication method of clients on the internet. Valid values: `Basic`, `Ntlm`, `Negotiate` (case-insensitive).
- `external_clients_require_ssl` (Boolean) Require SSL for clients on the internet. Exchange ignores it while `external_hostname` is empty.
- `external_hostname` (String) Host name used from the internet. An empty string clears it.
- `iis_authentication_methods` (Set of String) Authentication methods of the IIS directory. Valid values: `Basic`, `Ntlm`, `Negotiate` (case-insensitive).
- `internal_client_authentication_method` (String) Authentication method of clients inside the network. Valid values: `Basic`, `Ntlm`, `Negotiate` (case-insensitive).
- `internal_clients_require_ssl` (Boolean) Require SSL for clients inside the network.
- `internal_hostname` (String) Host name used inside the network, such as `mail.contoso.com`. An empty string clears it.
- `ssl_offloading` (Boolean) A load balancer in front of the server decrypts SSL: the directory does not require it.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's account needs `Get-OutlookAnywhere` and `Set-OutlookAnywhere`, from the **Exchange Servers** management role (in **Exchange Virtual Directories**, `Get-OutlookAnywhere` cannot name a server). The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only the `Get-` and `Set-` cmdlets the provider runs: the built-in role also changes DAG membership, maintenance mode and every server setting. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).

## Import

Import using the server name:

```terraform
import {

  id = "EX01"
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_outlook_anywhere.ex01
  identity = { id = "EX01" }
}
```

```shell
terraform import msexchangeserver_outlook_anywhere.ex01 "EX01"
```
