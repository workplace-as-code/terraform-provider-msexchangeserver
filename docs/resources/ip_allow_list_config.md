# msexchangeserver_ip_allow_list_config (Resource)

Manages the IP allow list of the connection filter agent (`Set-IPAllowListConfig`). This is a singleton: there is exactly one per organization. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. An Edge Transport setting: on a Mailbox server, it needs the anti-spam agents and the Transport Hygiene role.

## Example Usage

```terraform
resource "msexchangeserver_ip_allow_list_config" "this" {
  enabled = true
}
```

## Schema

### Optional

- `enabled` (Boolean) Whether the IP allow list is used.
- `external_mail_enabled` (Boolean) Use it for connections from outside the organization.
- `internal_mail_enabled` (Boolean) Use it for authenticated partners and internal servers.

### Read-Only

- `id` (String) Always `default`.

## Permissions

On an Edge Transport server, the account is a local administrator: Exchange has no role-based access control there. On a Mailbox server with the anti-spam agents installed, it needs the **Transport Hygiene** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) does not include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).

## Import

The resource is a singleton. Import it with the ID `default`:

```terraform
import {
  to = msexchangeserver_ip_allow_list_config.this
  id = "default"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_ip_allow_list_config.this
  identity = { id = "default" }
}
```

Or with the CLI:

```shell
terraform import msexchangeserver_ip_allow_list_config.this "default"
```

To import every existing object at once, see [Import an existing organization](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/import_existing).
