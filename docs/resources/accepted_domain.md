# msexchangeserver_accepted_domain (Resource)

Manages an accepted domain of the Exchange organization (`New-AcceptedDomain`). The default accepted domain cannot be removed.

## Example Usage

```terraform
resource "msexchangeserver_accepted_domain" "contoso_com" {
  name        = "Contoso"
  domain_name = "contoso.com"
  domain_type = "Authoritative"
}

resource "msexchangeserver_accepted_domain" "subsidiary_relay" {
  name        = "Subsidiary Internal Relay"
  domain_name = "subsidiary.contoso.com"
  domain_type = "InternalRelay"
}
```

## Schema

### Required

- `domain_name` (String) The SMTP domain (e.g. `contoso.com`).
- `name` (String) Friendly name for the accepted domain entry.

### Optional

- `domain_type` (String) Type of accepted domain: `Authoritative` (used when omitted), `InternalRelay` or `ExternalRelay`.
- `match_sub_domains` (Boolean) Also accept mail for all subdomains of this domain.

### Read-Only

- `default` (Boolean) Whether this is the default accepted domain (read-only).
- `id` (String) The unique identifier of the accepted domain.
