# msexchangeserver_mailbox_database (Resource)

Manages the quotas, retention and logging settings of a mailbox database. Mailboxes without quotas of their own use the database's (`Set-MailboxDatabase`). The object cannot be created: the resource adopts the existing one. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. `name` is the database name, unique in the organization. Databases are created and removed with the Exchange tools: the provider never mounts, dismounts or removes them. Sizes are in megabytes, `0` meaning unlimited.

## Example Usage

```terraform
# Default quotas of the mailboxes of DB01, and 30 days to recover deleted items.
resource "msexchangeserver_mailbox_database" "db01" {
  name                           = "DB01"
  issue_warning_quota_mb         = 47104
  prohibit_send_quota_mb         = 49152
  prohibit_send_receive_quota_mb = 51200
  deleted_item_retention_days    = 30
}
```

## Schema

### Required

- `name` (String) The name of the existing object. Changing it adopts another object and leaves this one as it is.

### Optional

- `calendar_logging_quota_mb` (Number) Largest size of the calendar log in the Recoverable Items folder.
- `circular_logging_enabled` (Boolean) Overwrite the transaction logs once their changes are in the database. Outside a database availability group, the change applies after the database is next mounted.
- `deleted_item_retention_days` (Number) Days deleted items stay recoverable.
- `is_excluded_from_provisioning` (Boolean) Exclude the database from the automatic placement of new mailboxes.
- `issue_warning_quota_mb` (Number) Mailbox size at which users are warned.
- `mailbox_retention_days` (Number) Days a deleted mailbox is kept in the database.
- `mount_at_startup` (Boolean) Mount the database when the Information Store service starts.
- `offline_address_book` (String) Offline address book of the mailboxes of the database, by name.
- `prohibit_send_quota_mb` (Number) Mailbox size at which users can no longer send.
- `prohibit_send_receive_quota_mb` (Number) Mailbox size at which the mailbox can no longer send or receive.
- `recoverable_items_quota_mb` (Number) Largest size of the Recoverable Items folder.
- `recoverable_items_warning_quota_mb` (Number) Size of the Recoverable Items folder at which Exchange logs a warning.
- `retain_deleted_items_until_backup` (Boolean) Keep deleted items and mailboxes until the database is backed up, even after their retention period.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's account needs `Get-MailboxDatabase` and `Set-MailboxDatabase`, from the **Databases** management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only these cmdlets: the built-in role can also mount, dismount, move and remove databases. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).

## Import

Import using the database name:

```terraform
import {
  to = msexchangeserver_mailbox_database.db01
  id = "DB01"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_mailbox_database.db01
  identity = { id = "DB01" }
}
```

Or with the CLI:

```shell
terraform import msexchangeserver_mailbox_database.db01 "DB01"
```

To import every existing object at once, see [Import an existing organization](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/import_existing).
