# msexchangeserver_remote_domain (Resource)

Manages a remote domain (email routing and security settings for a specific external domain).

## Example Usage

```terraform
# Restrict email settings for a partner domain
resource "msexchangeserver_remote_domain" "partner" {
  name        = "Contoso-Partner"
  domain_name = "partner.contoso.com"

  auto_reply_enabled            = false
  auto_forward_enabled          = false
  trusted_mail_outbound_enabled = true
  allowed_oof_type              = "None"
}

# Default wildcard remote domain with relaxed settings
resource "msexchangeserver_remote_domain" "internet" {
  name        = "Internet"
  domain_name = "*"

  auto_reply_enabled   = true
  auto_forward_enabled = false
  allowed_oof_type     = "External"
}
```

## Schema

### Required

- `domain_name` (String) The SMTP domain (e.g. `partner-bank.com`). Immutable after creation.
- `name` (String) Display name for the remote domain entry.

### Optional

- `allowed_oof_type` (String) Type of out-of-office messages allowed. Valid values: `External`, `ExternalLegacy`, `InternalLegacy`, `None`.
- `auto_forward_enabled` (Boolean) Allow auto-forwarding of messages to recipients in this domain.
- `auto_reply_enabled` (Boolean) Allow automatic replies to recipients in this domain.
- `tnef_enabled` (String) TNEF (Winmail.dat) encoding. `"true"` to force, `"false"` to disable, `""` to inherit the organization default.
- `trusted_mail_inbound_enabled` (Boolean) Trust inbound mail from this domain (bypass some spam filters).
- `trusted_mail_outbound_enabled` (Boolean) Trust outbound mail to this domain.

### Read-Only

- `id` (String) The unique identifier of the remote domain (same as `name`).

## Permissions

The provider's account needs the **Remote and Accepted Domains** management role, which the **Organization Management** role group includes. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
