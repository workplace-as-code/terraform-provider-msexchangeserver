# msexchangeserver_mobile_device_mailbox_policy (Resource)

Manages an Exchange Mobile Device Mailbox Policy. Controls security settings for mobile devices connecting via Exchange ActiveSync.

## Example Usage

```terraform
# Corporate BYOD strict policy
resource "msexchangeserver_mobile_device_mailbox_policy" "byod_strict" {
  name                           = "BYOD Strict"
  password_enabled               = true
  alphanumeric_password_required = true
  min_password_length            = 8
  max_password_failed_attempts   = 5
  max_inactivity_time_lock       = "00:05:00"
  device_encryption_enabled      = true
  require_device_encryption      = true
  allow_camera                   = false
  allow_text_messaging           = false
  allow_bluetooth                = "HandsfreeOnly"
}

# Default permissive policy
resource "msexchangeserver_mobile_device_mailbox_policy" "default" {
  name       = "Default"
  is_default = true
}
```

## Schema

### Required

- `name` (String) Name of the policy. Immutable after creation.

### Optional

- `allow_bluetooth` (String) Bluetooth setting. Valid values: `Allow`, `Disable`, `HandsfreeOnly`.
- `allow_browser` (Boolean) Allow the built-in web browser.
- `allow_camera` (Boolean) Allow the device camera.
- `allow_simple_password` (Boolean) Allow simple numeric passwords.
- `allow_storage_card` (Boolean) Allow removable storage cards.
- `allow_text_messaging` (Boolean) Allow SMS / text messaging.
- `allow_wifi` (Boolean) Allow Wi-Fi connections.
- `alphanumeric_password_required` (Boolean) Require an alphanumeric password.
- `device_encryption_enabled` (Boolean) Require device encryption.
- `is_default` (Boolean) Set this policy as the default mobile device mailbox policy.
- `max_inactivity_time_lock` (String) Screen lock timeout as a timespan string (e.g. `00:05:00` for 5 minutes).
- `max_password_failed_attempts` (Number) Failed password attempts before the device is wiped, from 4 to 16. `0` means unlimited.
- `min_password_length` (Number) Minimum password length.
- `password_enabled` (Boolean) Require a password on the device.
- `password_recovery_enabled` (Boolean) Enable password recovery.
- `require_device_encryption` (Boolean) Enforce storage card encryption.

### Read-Only

- `id` (String) The unique identifier of the mobile device mailbox policy.
