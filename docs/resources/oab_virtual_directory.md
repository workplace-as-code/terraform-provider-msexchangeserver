# msexchangeserver_oab_virtual_directory (Resource)

Manages the URLs and the authentication settings of the offline address book (OAB) virtual directory of an Exchange server (`Set-OabVirtualDirectory`). The object cannot be created: the resource adopts the existing one. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. `name` is the server name or FQDN, for the virtual directory of the Default Web Site, or its identity as `Get-OabVirtualDirectory` shows it, such as `EX01\OAB (Default Web Site)`. Authentication settings are read from IIS: a plan fails when the server's IIS does not answer.

## Example Usage

```terraform
# The same namespace inside and outside the network.
resource "msexchangeserver_oab_virtual_directory" "ex01" {
  name         = "EX01"
  internal_url = "https://mail.contoso.com/OAB"
  external_url = "https://mail.contoso.com/OAB"
}
```

## Schema

### Required

- `name` (String) The name of the existing object. Changing it adopts another object and leaves this one as it is.

### Optional

- `basic_authentication` (Boolean) Basic authentication in IIS.
- `external_url` (String) URL used from the internet. An empty string clears it.
- `internal_url` (String) URL used inside the network. An empty string clears it.
- `oauth_authentication` (Boolean) OAuth authentication.
- `require_ssl` (Boolean) Require SSL in IIS.
- `windows_authentication` (Boolean) Integrated Windows authentication in IIS.

### Read-Only

- `extended_protection_token_checking` (String) Extended Protection: `None`, `Allow` or `Require`. Read only: set it with Microsoft's Extended Protection script.
- `external_authentication_methods` (Set of String) Authentication methods Exchange advertises to clients on the internet.
- `id` (String) The object name (same as `name`).
- `internal_authentication_methods` (Set of String) Authentication methods Exchange advertises to clients inside the network.

## Permissions

The provider's account needs `Get-OabVirtualDirectory` and `Set-OabVirtualDirectory`, from the **Exchange Virtual Directories** management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only the `Get-` and `Set-` cmdlets of the virtual directories: the built-in role can also create and remove them. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).

## Import

Import using the server name:

```terraform
import {
  to = msexchangeserver_oab_virtual_directory.ex01
  id = "EX01"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_oab_virtual_directory.ex01
  identity = { id = "EX01" }
}
```

Or with the CLI:

