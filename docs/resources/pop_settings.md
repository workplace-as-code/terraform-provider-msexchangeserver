# msexchangeserver_pop_settings (Resource)

Manages the POP3 settings of an Exchange server: sign-in, certificate, bindings and connection limits (`Set-PopSettings`). The object cannot be created: the resource adopts the existing one. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. `name` is the server name or FQDN. Exchange applies a change once the Microsoft Exchange Pop3 services of the server restart, which the provider does not do. The certificate is bound to POP3 with `msexchangeserver_exchange_certificate_services`.

## Example Usage

```terraform
# POP3 on EX01: encrypted connections only, with the certificate of mail.contoso.com.
resource "msexchangeserver_pop_settings" "ex01" {
  name                         = "EX01"
  login_type                   = "SecureLogin"
  x509_certificate_name        = "mail.contoso.com"
  internal_connection_settings = ["mail.contoso.com:995:SSL"]
  ssl_bindings                 = ["0.0.0.0:995", "[::]:995"]
  max_connections_per_user     = 4
}
```

## Schema

### Required

- `name` (String) The name of the existing object. Changing it adopts another object and leaves this one as it is.

### Optional

- `external_connection_settings` (Set of String) Host names, ports and encryption shown to clients on the internet, as `mail.contoso.com:995:SSL`.
- `internal_connection_settings` (Set of String) Host names, ports and encryption shown to clients inside the network, as `mail.contoso.com:995:SSL`.
- `login_type` (String) Sign-in method. `SecureLogin`, the Exchange default, accepts a clear-text password only on an encrypted connection. Valid values: `PlainTextLogin`, `PlainTextAuthentication`, `SecureLogin` (case-insensitive).
- `max_connection_from_single_ip` (Number) Largest number of connections from one IP address.
- `max_connections` (Number) Largest number of connections to the server.
- `max_connections_per_user` (Number) Largest number of connections of one user.
- `ssl_bindings` (Set of String) Addresses and ports of the SSL connections, as `0.0.0.0:995`.
- `unencrypted_or_tls_bindings` (Set of String) Addresses and ports of the unencrypted and TLS (STARTTLS) connections, as `0.0.0.0:110`.
- `x509_certificate_name` (String) Host name of the certificate used for SSL and TLS, such as `mail.contoso.com`.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's account needs `Get-PopSettings` and `Set-PopSettings`, from the **POP3 And IMAP4 Protocols** management role, and `Get-ExchangeServer`. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
