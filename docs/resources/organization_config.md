# msexchangeserver_organization_config (Resource)

Manages Exchange organization-wide configuration settings (`Set-OrganizationConfig`). This is a singleton resource: there is exactly one organization config per organization. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing the Exchange configuration.

## Example Usage

```terraform
resource "msexchangeserver_organization_config" "org" {
  read_tracking_enabled                      = false
  mail_tips_all_tips_enabled                 = true
  mail_tips_external_recipients_tips_enabled = true
  mail_tips_large_audience_threshold         = 25
  oauth2_client_profile_enabled              = true
}
```

## Schema

### Optional

- `mail_tips_all_tips_enabled` (Boolean) Enable MailTips for the organization. When `false`, all MailTips are disabled regardless of individual settings.
- `mail_tips_external_recipients_tips_enabled` (Boolean) Show a MailTip when composing a message to external recipients.
- `mail_tips_large_audience_threshold` (Number) Number of recipients above which the large-audience MailTip is shown.
- `oauth2_client_profile_enabled` (Boolean) Enable modern authentication (OAuth 2.0) for Outlook and other clients (hybrid modern authentication).
- `read_tracking_enabled` (Boolean) Enable read tracking so senders can see when their messages were read.

### Read-Only

- `id` (String) Always `"organization"`. This is a singleton resource.

The provider's account needs the **Organization Configuration** management role, which the **Organization Management** role group includes. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).

## Import

The resource is a singleton. Import it with the ID `organization`:

```terraform
import {
  to = msexchangeserver_organization_config.this
  id = "organization"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_organization_config.this
  identity = { id = "organization" }
}
```

Or with the CLI:

```shell
terraform import msexchangeserver_organization_config.this "organization"
```

To import every existing object at once, see [Import an existing organization](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/import_existing).
