# msexchangeserver_address_list (Resource)

Manages an address list: the recipients that match a filter, shown in Outlook and usable in an address book policy (`New-AddressList`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. The provider never recalculates members: a recipient enters or leaves the list when its own object next changes, or when an administrator runs `Update-AddressList`. Precanned filters (`-IncludedRecipients` and `-Conditional*`) are not managed: an imported precanned list shows the equivalent filter in `recipient_filter`, and applying writes it as a custom filter.

## Example Usage

```terraform
# The users of the Paris office, as a list nested in a "Sites" list.
resource "msexchangeserver_address_list" "paris" {
  name             = "Paris"
  container        = "Sites"
  recipient_filter = "Office -eq 'Paris' -and RecipientType -eq 'UserMailbox'"
}

# The room mailboxes, for the room list of an address book policy.
resource "msexchangeserver_address_list" "contoso_rooms" {
  name                = "Contoso Rooms"
  recipient_filter    = "RecipientDisplayType -eq 'ConferenceRoomMailbox'"
  recipient_container = "contoso.com/Contoso"
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `container` (String) Name of the parent address list, for a list nested in another one. Empty for a top-level list. Changing it creates a new list.
- `display_name` (String) The name shown in Outlook. Defaults to `name`.
- `recipient_container` (String) Organizational unit the filter applies to, as a canonical name (`contoso.com/Paris`). `""` applies it to the whole organization. Only recipients in this unit can be in the list.
- `recipient_filter` (String) OPATH filter of the recipients in the list, for example `Company -eq 'Contoso' -and RecipientType -eq 'UserMailbox'`. Exchange rewrites it with parentheses: the configured text is kept as long as Exchange returns the text it wrote.

### Read-Only

- `id` (String) The object name (same as `name`).

## Import

Import using the list name:

```terraform
import {
  to = msexchangeserver_address_list.paris
  id = "Paris"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_address_list.paris
  identity = { id = "Paris" }
}
```

Or with the CLI:

```shell
terraform import msexchangeserver_address_list.paris "Paris"
```

To import every existing object at once, see [Import an existing organization](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/import_existing).
