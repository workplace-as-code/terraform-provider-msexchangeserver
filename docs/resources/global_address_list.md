# msexchangeserver_global_address_list (Resource)

Manages a global address list (GAL), the main address list of an address book policy (`New-GlobalAddressList`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. The default GAL, `Default Global Address List`, cannot be changed: import it or use the data source to read it. The provider never recalculates members: a recipient enters or leaves the list when its own object next changes, or when an administrator runs `Update-GlobalAddressList`.

## Example Usage

```terraform
# The GAL of the Contoso entity: its recipients carry Contoso in CustomAttribute1.
resource "msexchangeserver_global_address_list" "contoso" {
  name             = "Contoso GAL"
  recipient_filter = "CustomAttribute1 -eq 'Contoso'"
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `recipient_container` (String) Organizational unit the filter applies to, as a canonical name (`contoso.com/Paris`). `""` applies it to the whole organization. Only recipients in this unit can be in the GAL.
- `recipient_filter` (String) OPATH filter of the recipients in the GAL, for example `CustomAttribute1 -eq 'Contoso'`. Exchange rewrites it with parentheses: the configured text is kept as long as Exchange returns the text it wrote.

### Read-Only

- `id` (String) The object name (same as `name`).

## Import

Import using the GAL name:

```terraform
import {
  to = msexchangeserver_global_address_list.contoso
  id = "Contoso GAL"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_global_address_list.contoso
  identity = { id = "Contoso GAL" }
}
```

Or with the CLI:

```shell
terraform import msexchangeserver_global_address_list.contoso "Contoso GAL"
```

To import every existing object at once, see [Import an existing organization](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/import_existing).
