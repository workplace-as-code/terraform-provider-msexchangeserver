# msexchangeserver_transport_config (Resource)

Manages the organization-wide transport settings (`Set-TransportConfig`). This is a singleton: there is exactly one per organization. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange.

## Example Usage

```terraform
# Message limits of the organization, postmaster address and shadow redundancy.
resource "msexchangeserver_transport_config" "this" {
  max_send_size_mb             = 35
  max_receive_size_mb          = 35
  max_recipient_envelope_limit = 500

  external_postmaster_address = "postmaster@contoso.com"
  internal_smtp_servers       = ["10.0.0.25"]

  shadow_redundancy_enabled    = true
  safety_net_hold_time_minutes = 2880
}
```

## Schema

### Optional

- `address_book_policy_routing_enabled` (Boolean) Resolve recipients to the global address list of the sender's address book policy.
- `clear_categories` (Boolean) Remove the Outlook categories of messages during content conversion.
- `convert_disclaimer_wrapper_to_eml` (Boolean) Attach the original message as an .eml file when a transport rule disclaimer cannot be inserted.
- `dsn_conversion_mode` (String) How delivery status notifications from other messaging systems are converted. Valid values: `UseExchangeDSNs`, `PreserveDSNBody`, `DoNotConvert` (case-insensitive).
- `external_delay_dsn_enabled` (Boolean) Send delay notifications to external senders.
- `external_dsn_reporting_authority` (String) Domain shown in the machine-readable part of the delivery status notifications sent outside the organization. Exchange uses the authoritative domain when it is not set.
- `external_dsn_send_html` (Boolean) Send the delivery status notifications to external senders in HTML (otherwise plain text).
- `external_postmaster_address` (String) Sender address of the delivery status notifications sent to external senders.
- `generate_copy_of_dsn_for` (List of String) Enhanced status codes (for example `5.4.8`) of the non-delivery reports copied to the Exchange recipient (the postmaster mailbox).
- `header_promotion_mode_setting` (String) Whether named properties are created for the custom X-headers of received messages. Valid values: `NoCreate`, `MayCreate`, `MustCreate` (case-insensitive).
- `internal_delay_dsn_enabled` (Boolean) Send delay notifications to internal senders.
- `internal_dsn_reporting_authority` (String) Domain shown in the machine-readable part of the delivery status notifications sent inside the organization. Exchange uses the authoritative domain when it is not set.
- `internal_dsn_send_html` (Boolean) Send the delivery status notifications to internal senders in HTML (otherwise plain text).
- `internal_smtp_servers` (List of String) IP addresses or ranges of the internal SMTP servers, ignored by Sender ID and connection filtering (for example a load balancer or a relay in front of Exchange).
- `journaling_report_ndr_to` (String) Mailbox that receives the journal reports that could not be delivered to the journaling mailbox.
- `max_receive_size_mb` (Number) Largest message, in megabytes, that a user can receive. `0` means unlimited. Connectors and mailboxes can set lower limits.
- `max_recipient_envelope_limit` (Number) Largest number of recipients in a message, a distribution group counting as one. `0` means unlimited.
- `max_send_size_mb` (Number) Largest message, in megabytes, that a user can send. `0` means unlimited. Connectors and mailboxes can set lower limits.
- `reject_message_on_shadow_failure` (Boolean) Reject a message when no shadow copy can be made.
- `rfc2231_encoding_enabled` (Boolean) Encode attachment names with RFC 2231.
- `safety_net_hold_time_minutes` (Number) Minutes during which Safety Net keeps a copy of the delivered messages, for redelivery after a database failover: `2880` (2 days) by default on Mailbox servers, `10` on Edge Transport servers.
- `shadow_message_preference_setting` (String) Where the shadow copy is made: a server of the same Active Directory site, of another site, or of another site when one is available. Valid values: `LocalOnly`, `RemoteOnly`, `PreferRemote` (case-insensitive).
- `shadow_redundancy_enabled` (Boolean) Keep a shadow copy of every message on another transport server until it is delivered.
- `tls_receive_domain_secure_list` (List of String) Domains from which mail is received with mutual TLS authentication (domain security).
- `tls_send_domain_secure_list` (List of String) Domains to which mail is sent with mutual TLS authentication (domain security).
- `voicemail_journaling_enabled` (Boolean) Journal the voice mail and missed call notifications.

### Read-Only

- `id` (String) Always `default`.

## Import

The resource is a singleton. Import it with the ID `default`:

```terraform
import {
  to = msexchangeserver_transport_config.this
  id = "default"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_transport_config.this
  identity = { id = "default" }
}
```

Or with the CLI:

```shell
terraform import msexchangeserver_transport_config.this "default"
```

To import every existing object at once, see [Import an existing organization](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/import_existing).
