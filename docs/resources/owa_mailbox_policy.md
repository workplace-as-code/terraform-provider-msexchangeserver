# msexchangeserver_owa_mailbox_policy (Resource)

Manages an OWA (Outlook on the web) mailbox policy. Policies are assigned to mailboxes via `Set-CASMailbox -OwaMailboxPolicy`.

## Example Usage

```terraform
# Hardened OWA policy for standard users — disables risky features
resource "msexchangeserver_owa_mailbox_policy" "standard" {
  name = "Standard-OWA"

  # Keep productivity features enabled
  attachments_enabled           = true
  recover_deleted_items_enabled = true
  rules_enabled                 = true
  signatures_enabled            = true

  # Disable features that increase the attack surface
  instant_messaging_enabled       = false
  active_sync_integration_enabled = false
  public_folders_enabled          = false
  theme_selection_enabled         = false

  # Office Online document viewing
  wac_viewing_on_private_computers_enabled = true
  wac_viewing_on_public_computers_enabled  = false

  # Security headers and encoding
  web_parts_frame_options_type = "SameOrigin"
  outbound_charset             = "AlwaysUTF8"

  # Block dangerous attachment types in OWA
  blocked_file_types = ["exe", "bat", "cmd", "ps1", "vbs", "js", "jar", "scr"]
}

# Permissive OWA policy for IT administrators
resource "msexchangeserver_owa_mailbox_policy" "it_admins" {
  name = "IT-Admins-OWA"

  attachments_enabled             = true
  recover_deleted_items_enabled   = true
  rules_enabled                   = true
  signatures_enabled              = true
  instant_messaging_enabled       = true
  active_sync_integration_enabled = true
  public_folders_enabled          = true
  theme_selection_enabled         = true

  wac_viewing_on_private_computers_enabled = true
  wac_viewing_on_public_computers_enabled  = true

  web_parts_frame_options_type = "SameOrigin"
  outbound_charset             = "AlwaysUTF8"
}
```

## Schema

### Required

- `name` (String) The name of the OWA mailbox policy. Immutable after creation.

### Optional

- `active_sync_integration_enabled` (Boolean) Show ActiveSync device management options in Outlook on the Web.
- `attachments_enabled` (Boolean) Allow users to open and send attachments in Outlook on the Web.
- `blocked_file_types` (Set of String) File extensions blocked as email attachments in Outlook on the Web (e.g. `["exe", "bat"]`). Order does not matter.
- `blocked_mime_types` (Set of String) MIME types blocked as email attachments in Outlook on the Web (e.g. `["application/x-javascript"]`). Order does not matter.
- `instant_messaging_enabled` (Boolean) Allow instant messaging in Outlook on the Web.
- `outbound_charset` (String) Character set for outbound messages. Valid values: `AlwaysUTF8`, `AutoDetect`, `UserLanguageChoice`.
- `public_folders_enabled` (Boolean) Allow access to public folders in Outlook on the Web.
- `recover_deleted_items_enabled` (Boolean) Allow users to recover deleted items from the Recoverable Items folder.
- `rules_enabled` (Boolean) Allow users to create and manage inbox rules in Outlook on the Web.
- `signatures_enabled` (Boolean) Allow users to create and use email signatures.
- `theme_selection_enabled` (Boolean) Allow users to select a theme in Outlook on the Web.
- `wac_viewing_on_private_computers_enabled` (Boolean) Allow Office Online (WAC) document viewing on private computers.
- `wac_viewing_on_public_computers_enabled` (Boolean) Allow Office Online (WAC) document viewing on public computers.
- `web_parts_frame_options_type` (String) X-Frame-Options header behavior for Outlook on the Web. Valid values: `None`, `SameOrigin`, `Deny`.

### Read-Only

- `id` (String) The unique identifier of the OWA mailbox policy.
