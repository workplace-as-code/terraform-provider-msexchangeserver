# msexchangeserver_admin_audit_log_config (Resource)

Manages administrator audit logging: which cmdlets run by administrators are recorded, and for how long (`Set-AdminAuditLogConfig`). This is a singleton: there is exactly one per organization. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. Lowering `admin_audit_log_age_limit_days` deletes the older entries. A change can take up to 60 minutes to apply where an Exchange Management Shell is open. Mailbox audit logging is a setting of each mailbox: the provider does not manage it.

## Example Usage

```terraform
# Administrator audit log kept one year, with the old and new values of each change.
resource "msexchangeserver_admin_audit_log_config" "this" {
  admin_audit_log_enabled        = true
  admin_audit_log_age_limit_days = 365
  log_level                      = "Verbose"
}
```

## Schema

### Optional

- `admin_audit_log_age_limit_days` (Number) Days the entries are kept.
- `admin_audit_log_cmdlets` (Set of String) Cmdlets recorded, with wildcards (`*Mailbox*`). `["*"]` records every cmdlet.
- `admin_audit_log_enabled` (Boolean) Record the cmdlets run by administrators.
- `admin_audit_log_excluded_cmdlets` (Set of String) Cmdlets never recorded, with wildcards. Exchange refuses `*` alone.
- `admin_audit_log_parameters` (Set of String) Parameters recorded, with wildcards. `["*"]` records every parameter.
- `log_level` (String) `Verbose` also records the old and new values of the changed properties. Valid values: `None`, `Verbose` (case-insensitive).
- `test_cmdlet_logging_enabled` (Boolean) Record the Test- cmdlets too. They produce many entries.

### Read-Only

- `id` (String) Always `default`.

## Permissions

The provider's account needs `Get-AdminAuditLogConfig` and `Set-AdminAuditLogConfig`, from the **Audit Logs** management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only these cmdlets: the built-in role can also change mailboxes and search the audit logs. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).

## Import

The resource is a singleton. Import it with the ID `default`:

```terraform
import {
  to = msexchangeserver_admin_audit_log_config.this
  id = "default"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_admin_audit_log_config.this
  identity = { id = "default" }
```
