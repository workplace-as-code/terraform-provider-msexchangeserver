# msexchangeserver_retention_policy_tag (Resource)

Manages a retention policy tag (messaging records management), which sets how long items are kept and what happens when the age limit is reached. Link tags to mailboxes with `msexchangeserver_retention_policy` (`New-RetentionPolicyTag`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `type` is required to create a tag.

## Example Usage

```terraform
# Delete items in Deleted Items after 30 days.
resource "msexchangeserver_retention_policy_tag" "deleted_items" {
  name                    = "Deleted Items - 30 days"
  type                    = "DeletedItems"
  age_limit_for_retention = 30
  retention_action        = "DeleteAndAllowRecovery"
}

# Archive everything after two years.
resource "msexchangeserver_retention_policy_tag" "archive" {
  name                    = "Default - Archive after 2 years"
  type                    = "All"
  age_limit_for_retention = 730
  retention_action        = "MoveToArchive"
}

resource "msexchangeserver_retention_policy" "standard" {
  name = "Standard MRM"
  retention_policy_tag_links = [
    msexchangeserver_retention_policy_tag.deleted_items.name,
    msexchangeserver_retention_policy_tag.archive.name,
  ]
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `age_limit_for_retention` (Number) Age, in days, at which `retention_action` applies. `0` means no age limit, which Exchange only accepts with `retention_enabled = false` (built-in tags such as Never Delete).
- `comment` (String) Comment shown to users in Outlook.
- `retention_action` (String) Action when the age limit is reached. Valid values: `DeleteAndAllowRecovery`, `PermanentlyDelete`, `MoveToArchive`, `MarkAsPastRetentionLimit` (case-insensitive).
- `retention_enabled` (Boolean) Whether the tag is applied. `false` keeps it visible but inactive.
- `type` (String) Folder the tag applies to: `All` (default policy tag), `Personal` (users apply it themselves), or a default folder such as `Inbox`, `SentItems`, `DeletedItems`, `JunkEmail`, `Calendar`, `Tasks`, `RecoverableItems`. Changing it creates a new tag.

### Read-Only

- `id` (String) The object name (same as `name`).
