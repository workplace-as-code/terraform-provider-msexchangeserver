# msexchangeserver_authentication_policy (Resource)

Manages an authentication policy, which blocks Basic (legacy) or modern authentication protocol by protocol for the users it applies to (`New-AuthenticationPolicy`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. Exchange Server 2019 CU2 and later. A policy applies to the users it is assigned to (`Set-User`, out of the provider's scope) and, as the organization's `default_authentication_policy`, to every other user. Exchange refuses to remove the default policy. A change can take up to 30 minutes to apply.

## Example Usage

```terraform
# Basic authentication blocked for every protocol, set as the organization's default policy.
resource "msexchangeserver_authentication_policy" "block_basic" {
  name                                   = "Block Basic"
  block_legacy_auth_activesync           = true
  block_legacy_auth_autodiscover         = true
  block_legacy_auth_imap                 = true
  block_legacy_auth_mapi                 = true
  block_legacy_auth_offline_address_book = true
  block_legacy_auth_pop                  = true
  block_legacy_auth_rpc                  = true
  block_legacy_auth_web_services         = true
}

resource "msexchangeserver_organization_config" "this" {
  default_authentication_policy = msexchangeserver_authentication_policy.block_basic.name
}
```

## Permissions

The provider's account needs the **Organization Configuration** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) and the **Organization Management** role group include. The read account gets `Get-AuthenticationPolicy` from the read role group of the same script: View-Only Organization Management does not contain it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
