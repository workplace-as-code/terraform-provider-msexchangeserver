# msexchangeserver_email_address_policy (Resource)

Manages an email address policy, which defines how email addresses are generated for recipients. Exchange applies a new or changed policy to the recipients created or modified afterwards; existing recipients only get the new addresses when `Update-EmailAddressPolicy` runs, which `apply_to_recipients` does.

## Example Usage

```terraform
# Sales mailboxes get a first.last address in the sales subdomain. The existing
# Sales mailboxes get it too: apply_to_recipients runs Update-EmailAddressPolicy.
resource "msexchangeserver_email_address_policy" "sales" {
  name                            = "Sales Team"
  enabled_email_address_templates = ["SMTP:%g.%s@sales.contoso.com"]
  included_recipients             = "MailboxUsers"
  conditional_department          = "Sales"
  priority                        = 1
  apply_to_recipients             = true
}
```

## Schema

### Required

- `name` (String) Name of the email address policy.

### Optional

- `apply_to_recipients` (Boolean) Run `Update-EmailAddressPolicy` after the policy is created, and after an apply that changes its settings, so that the existing recipients matching its filter get the new addresses. Defaults to `false`: only the recipients created or modified afterwards are updated. Changing only this attribute applies nothing. Applying a policy to many recipients takes time: raise `EXCHANGE_SCRIPT_TIMEOUT` if needed. This is a setting of the provider, not of Exchange: an imported policy has none, so the first plan after an import shows it as a change, which only records it.
- `conditional_company` (String) Filter by company attribute (comma-separated for multiple values).
- `conditional_department` (String) Filter by department attribute (comma-separated for multiple values).
- `enabled_email_address_templates` (List of String) SMTP address templates (e.g. `SMTP:%g.%s@contoso.com`). The primary address uses `SMTP:` (uppercase).
- `included_recipients` (String) Recipient types to apply this policy to. Valid values: `AllRecipients` (used when omitted), `MailboxUsers`, `MailContacts`, `MailGroups`, `MailUsers`, `Resources`.
- `priority` (Number) Priority of the policy. Lower numbers take precedence. The default policy always comes last and reads as `0`.

### Read-Only

- `id` (String) The unique identifier of the email address policy.

## Applying the policy to existing recipients

Exchange applies a new or changed policy to the recipients created or modified afterwards. The existing recipients only get the new addresses when `Update-EmailAddressPolicy` runs:

- With `apply_to_recipients = true`, the provider runs it after creating the policy, and after every apply that changes one of its settings.
- With `apply_to_recipients` left out or `false`, it never runs: apply the policy yourself when you are ready, for example outside business hours, with `Update-EmailAddressPolicy -Identity "<name>"`.

Setting `apply_to_recipients` alone, for example on an imported policy, applies nothing: the policy is applied at the next change of its settings.

## Permissions

The provider's account needs the **E-Mail Address Policies** management role, which the **Organization Management** role group includes. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).

## Import

Import using the policy name:

```terraform
import {
  to = msexchangeserver_email_address_policy.example
  id = "Standard Email Format"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_email_address_policy.example
  identity = { id = "Standard Email Format" }
}
```

Or with the CLI:

```shell
terraform import msexchangeserver_email_address_policy.example "Standard Email Format"
```

To import every existing object at once, see [Import an existing organization](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/import_existing).
