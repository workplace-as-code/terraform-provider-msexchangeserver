# msexchangeserver_sender_filter_config (Resource)

Manages the sender filter agent, which blocks given senders and domains (`Set-SenderFilterConfig`). This is a singleton: there is exactly one per organization. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. An Edge Transport setting: on a Mailbox server, it needs the anti-spam agents and the Transport Hygiene role.

## Example Usage

```terraform
# Block mail without a sender and from two domains.
resource "msexchangeserver_sender_filter_config" "this" {
  blank_sender_blocking_enabled  = true
  blocked_domains_and_subdomains = ["spam.example", "phish.example"]
}
```

## Schema

### Optional

- `action` (String) What happens to a message from a blocked sender. Valid values: `Reject`, `StampStatus` (case-insensitive).
- `blank_sender_blocking_enabled` (Boolean) Block the messages without a sender.
- `blocked_domains` (Set of String) Blocked sender domains, without their subdomains.
- `blocked_domains_and_subdomains` (Set of String) Blocked sender domains, with their subdomains.
- `blocked_senders` (Set of String) Blocked sender addresses.
- `enabled` (Boolean) Whether the agent filters messages.
- `external_mail_enabled` (Boolean) Filter messages from outside the organization.
- `internal_mail_enabled` (Boolean) Filter messages from authenticated partners and internal servers.

### Read-Only

- `id` (String) Always `default`.

## Permissions

On an Edge Transport server, the account is a local administrator: Exchange has no role-based access control there. On a Mailbox server with the anti-spam agents installed, it needs the **Transport Hygiene** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) does not include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).

## Import

The resource is a singleton. Import it with the ID `default`:

```terraform
import {
  to = msexchangeserver_sender_filter_config.this
  id = "default"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_sender_filter_config.this
  identity = { id = "default" }
```
