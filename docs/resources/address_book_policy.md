# msexchangeserver_address_book_policy (Resource)

Manages an address book policy (ABP), which gives the mailboxes it is assigned to their own GAL, address lists, offline address book and room list (`New-AddressBookPolicy`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. All four references are required to create a policy; they are names of the corresponding resources. Assigning the policy to mailboxes (`Set-Mailbox -AddressBookPolicy`) is not managed.

## Example Usage

```terraform
# The address book of the Contoso entity: its GAL, OAB, room list and site lists.
resource "msexchangeserver_address_book_policy" "contoso" {
  name                 = "Contoso ABP"
  global_address_list  = "Contoso GAL"
  offline_address_book = "Contoso OAB"
  room_list            = "Contoso Rooms"
  address_lists        = ["Paris"]
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `address_lists` (Set of String) Names of the address lists users see besides the GAL.
- `global_address_list` (String) Name of the global address list.
- `offline_address_book` (String) Name of the offline address book.
- `room_list` (String) Name of the address list of the rooms users can book, an address list whose filter selects room mailboxes.

### Read-Only

- `id` (String) The object name (same as `name`).

## Import

Import using the policy name:

```terraform

  to = msexchangeserver_address_book_policy.contoso
  id = "Contoso ABP"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_address_book_policy.contoso
  identity = { id = "Contoso ABP" }
}
```

Or with the CLI:

```shell

```
