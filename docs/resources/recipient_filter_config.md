# msexchangeserver_recipient_filter_config (Resource)

Manages the recipient filter agent, which blocks messages to given or unknown recipients (`Set-RecipientFilterConfig`). This is a singleton: there is exactly one per organization. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. An Edge Transport setting: on a Mailbox server, it needs the anti-spam agents and the Transport Hygiene role.

## Example Usage

```terraform
# Reject mail to recipients that do not exist.
resource "msexchangeserver_recipient_filter_config" "this" {
  recipient_validation_enabled = true
}
```

## Schema

### Optional

- `block_list_enabled` (Boolean) Block the messages to `blocked_recipients`.
- `blocked_recipients` (Set of String) Recipient addresses that never receive mail from outside.
- `enabled` (Boolean) Whether the agent filters messages.
- `external_mail_enabled` (Boolean) Filter messages from outside the organization.
- `internal_mail_enabled` (Boolean) Filter messages from authenticated partners and internal servers.
- `recipient_validation_enabled` (Boolean) Reject the messages to recipients that do not exist.

### Read-Only

- `id` (String) Always `default`.

## Permissions

On an Edge Transport server, the account is a local administrator: Exchange has no role-based access control there. On a Mailbox server with the anti-spam agents installed, it needs the **Transport Hygiene** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) does not include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).

## Import

The resource is a singleton. Import it with the ID `default`:

```terraform
import {
  to = msexchangeserver_recipient_filter_config.this
  id = "default"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeserver_recipient_filter_config.this
  identity = { id = "default" }
}
```

Or with the CLI:

```shell
terraform import msexchangeserver_recipient_filter_config.this "default"
```

To import every existing object at once, see [Import an existing organization](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/import_existing).
