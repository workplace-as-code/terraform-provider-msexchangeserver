# msexchangeserver_address_rewrite_entry (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_address_rewrite_entry`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/address_rewrite_entry) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_address_rewrite_entry" "this" {
  name = "Fabrikam to Contoso"
}

output "external_address" {
  description = "External address of the address rewrite entry."
  value       = data.msexchangeserver_address_rewrite_entry.this.external_address
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `exception_list` (Set of String) Subdomains of a wildcard `internal_address` that are not rewritten.
- `external_address` (String) Address or domain the messages show outside.
- `id` (String) The object name (same as `name`).
- `internal_address` (String) Address or domain inside the organization, such as `contoso.com` or `*.contoso.com`.
- `outbound_only` (Boolean) Rewrite outgoing messages only. Required with a wildcard `internal_address`.

## Permissions

On an Edge Transport server, the account is a local administrator: Exchange has no role-based access control there. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
