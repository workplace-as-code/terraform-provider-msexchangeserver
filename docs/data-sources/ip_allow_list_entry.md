# msexchangeserver_ip_allow_list_entry (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_ip_allow_list_entry`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/ip_allow_list_entry) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_ip_allow_list_entry" "this" {
  name = "192.0.2.0/24"
}

output "comment" {
  description = "Comment of the ip allow list entry."
  value       = data.msexchangeserver_ip_allow_list_entry.this.comment
}
```

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `comment` (String) Free text about the entry.
- `expiration_time` (String) When the entry expires, in RFC 3339 format and UTC, for example `2027-01-31T00:00:00Z`. Empty never expires.
- `id` (String) The object name (same as `name`).

## Permissions

On an Edge Transport server, the account is a local administrator: Exchange has no role-based access control there. On a Mailbox server with the anti-spam agents installed, it needs the **Transport Hygiene** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) does not include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
