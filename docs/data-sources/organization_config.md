# msexchangeserver_organization_config (Data Source)

Reads the organization configuration. Use this data source to reference organization-wide settings in other resources.

## Example Usage

```terraform
data "msexchangeserver_organization_config" "org" {}

output "organization_name" {
  description = "Display name of the Exchange organization."
  value       = data.msexchangeserver_organization_config.org.display_name
}
```

## Schema

### Read-Only

- `display_name` (String) The display name of the organization.
- `id` (String) The Exchange identity of the organization configuration object.
- `read_tracking_enabled` (Boolean) Whether read receipt tracking is enabled for the organization.
- `scl_junk_threshold` (Number) The spam confidence level (SCL) threshold above which messages are moved to the Junk Email folder.

## Permissions

The provider's account needs the **Organization Configuration** management role, which the **Organization Management** role group includes. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
