# msexchangeserver_email_address_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_email_address_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/email_address_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_email_address_policy" "this" {
  name = "Default Policy"
}

output "enabled_email_address_templates" {
  description = "Address templates of the default email address policy."
  value       = data.msexchangeserver_email_address_policy.this.enabled_email_address_templates
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `apply_to_recipients` (Boolean) Run `Update-EmailAddressPolicy` after the policy is created, and after an apply that changes its settings, so that the existing recipients matching its filter get the new addresses. Defaults to `false`: only the recipients created or modified afterwards are updated. Changing only this attribute applies nothing. Applying a policy to many recipients takes time: raise `EXCHANGE_SCRIPT_TIMEOUT` if needed. This is a setting of the provider, not of Exchange: an imported policy has none, so the first plan after an import shows it as a change, which only records it.
- `conditional_company` (String) Filter by company attribute (comma-separated for multiple values).
- `conditional_department` (String) Filter by department attribute (comma-separated for multiple values).
- `enabled_email_address_templates` (List of String) SMTP address templates (e.g. `SMTP:%g.%s@contoso.com`). The primary address uses `SMTP:` (uppercase).
- `id` (String) The unique identifier of the email address policy.
- `included_recipients` (String) Recipient types to apply this policy to. Valid values: `AllRecipients` (used when omitted), `MailboxUsers`, `MailContacts`, `MailGroups`, `MailUsers`, `Resources`.
- `priority` (Number) Priority of the policy. Lower numbers take precedence. The default policy always comes last and reads as `0`.

## Permissions

The provider's account needs the **E-Mail Address Policies** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) and the **Organization Management** role group include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
