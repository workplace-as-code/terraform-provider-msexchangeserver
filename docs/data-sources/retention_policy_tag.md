# msexchangeserver_retention_policy_tag (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_retention_policy_tag`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/retention_policy_tag) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_retention_policy_tag" "this" {
  name = "Deleted Items"
}

output "age_limit_for_retention" {
  description = "Days before deleted items are removed."
  value       = data.msexchangeserver_retention_policy_tag.this.age_limit_for_retention
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `age_limit_for_retention` (Number) Age, in days, at which `retention_action` applies. `0` means no age limit, which Exchange only accepts with `retention_enabled = false` (built-in tags such as Never Delete).
- `comment` (String) Comment shown to users in Outlook.
- `id` (String) The object name (same as `name`).
- `retention_action` (String) Action when the age limit is reached. Valid values: `DeleteAndAllowRecovery`, `PermanentlyDelete`, `MoveToArchive`, `MarkAsPastRetentionLimit` (case-insensitive).
- `retention_enabled` (Boolean) Whether the tag is applied. `false` keeps it visible but inactive.
- `type` (String) Folder the tag applies to: `All` (default policy tag), `Personal` (users apply it themselves), or a default folder such as `Inbox`, `SentItems`, `DeletedItems`, `JunkEmail`, `Calendar`, `Tasks`, `RecoverableItems`. Changing it creates a new tag.

## Permissions

The provider's account needs the retention policy cmdlets of the **Retention Management** management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only these cmdlets. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
