# msexchangeserver_remote_domain (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_remote_domain`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/remote_domain) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_remote_domain" "this" {
  name = "Default"
}

output "auto_forward_enabled" {
  description = "Whether automatic forwarding is allowed to external domains."
  value       = data.msexchangeserver_remote_domain.this.auto_forward_enabled
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `allowed_oof_type` (String) Type of out-of-office messages allowed. Valid values: `External`, `ExternalLegacy`, `InternalLegacy`, `None`.
- `auto_forward_enabled` (Boolean) Allow auto-forwarding of messages to recipients in this domain.
- `auto_reply_enabled` (Boolean) Allow automatic replies to recipients in this domain.
- `domain_name` (String) The SMTP domain (e.g. `partner-bank.com`). Immutable after creation.
- `id` (String) The unique identifier of the remote domain (same as `name`).
- `tnef_enabled` (String) TNEF (Winmail.dat) encoding. `"true"` to force, `"false"` to disable, `""` to inherit the organization default.
- `trusted_mail_inbound_enabled` (Boolean) Trust inbound mail from this domain (bypass some spam filters).
- `trusted_mail_outbound_enabled` (Boolean) Trust outbound mail to this domain.

## Permissions

The provider's account needs the **Remote and Accepted Domains** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) and the **Organization Management** role group include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
