# msexchangeserver_address_book_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_address_book_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/address_book_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_address_book_policy" "contoso" {
  name = "Contoso ABP"
}

output "contoso_gal" {
  description = "GAL of the Contoso address book policy."
  value       = data.msexchangeserver_address_book_policy.contoso.global_address_list
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `address_lists` (Set of String) Names of the address lists users see besides the GAL.
- `global_address_list` (String) Name of the global address list.
- `id` (String) The object name (same as `name`).
- `offline_address_book` (String) Name of the offline address book.
- `room_list` (String) Name of the address list of the rooms users can book, an address list whose filter selects room mailboxes.

## Permissions

The provider's account needs the **Address Lists** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) and the **Organization Management** role group include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
