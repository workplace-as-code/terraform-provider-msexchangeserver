# msexchangeserver_offline_address_book (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_offline_address_book`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/offline_address_book) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_offline_address_book" "default" {
  name = "Default Offline Address Book"
}

output "default_oab_lists" {
  description = "Address lists of the default offline address book."
  value       = data.msexchangeserver_offline_address_book.default.address_lists
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `address_lists` (Set of String) Names of the address lists in the offline address book, usually a GAL.
- `generating_mailbox` (String) Name of the arbitration mailbox that generates the offline address book, for example `SystemMailbox{bb558c35-97f1-4cb9-8ff7-d53741dc928c}`.
- `global_web_distribution_enabled` (Boolean) Whether every OAB virtual directory of the organization distributes the offline address book. Turning it on removes the `virtual_directories`.
- `id` (String) The object name (same as `name`).
- `is_default` (Boolean) Whether this is the default offline address book, used by the mailbox databases that name none. It cannot be set to `false` on the default one: set it to `true` on another offline address book, which turns this one off.
- `virtual_directories` (Set of String) OAB virtual directories that distribute the offline address book, for example `EX01\OAB (Default Web Site)`. Cannot be set with `global_web_distribution_enabled = true`.

## Permissions

The provider's account needs the **Address Lists** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) and the **Organization Management** role group include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
