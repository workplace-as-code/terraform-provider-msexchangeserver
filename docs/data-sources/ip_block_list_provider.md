# msexchangeserver_ip_block_list_provider (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_ip_block_list_provider`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/ip_block_list_provider) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_ip_block_list_provider" "this" {
  name = "Spamhaus"
}

output "lookup_domain" {
  description = "Lookup domain of the ip block list provider."
  value       = data.msexchangeserver_ip_block_list_provider.this.lookup_domain
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `any_match` (Boolean) Block when the lookup returns any address.
- `bitmask_match` (String) Block when the returned address matches this bit mask, such as `127.0.0.1`.
- `enabled` (Boolean) Whether the provider is queried.
- `id` (String) The object name (same as `name`).
- `ip_addresses_match` (Set of String) Block when the lookup returns one of these addresses.
- `lookup_domain` (String) DNS zone of the block list, for example `zen.spamhaus.org`.
- `priority` (Number) Order in which the providers are queried, 1 first.
- `rejection_response` (String) Rejection text, up to 240 characters.

## Permissions

On an Edge Transport server, the account is a local administrator: Exchange has no role-based access control there. On a Mailbox server with the anti-spam agents installed, it needs the **Transport Hygiene** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) does not include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
