# msexchangeserver_exchange_certificate (Data Source)

Reads a certificate of an Exchange server (`Get-ExchangeCertificate`), such as the one a service uses before it is replaced, or a certificate that this configuration does not manage.

## Example Usage

```terraform
data "msexchangeserver_exchange_certificate" "mail" {
  server     = "EX01.contoso.com"
  thumbprint = "0123456789ABCDEF0123456789ABCDEF01234567"
}

output "mail_certificate_expires" {
  description = "End of validity of the certificate, in UTC."
  value       = data.msexchangeserver_exchange_certificate.mail.not_after
}
```

## Schema

### Required

- `server` (String) The Exchange server that holds the certificate, as a name or an FQDN.
- `thumbprint` (String) The thumbprint of the certificate: 40 hexadecimal characters.

### Read-Only

- `certificate_domains` (List of String) The domains of the certificate: its subject and subject alternative names.
- `friendly_name` (String) The friendly name of the certificate on the server.
- `has_private_key` (Boolean) Whether the server has the private key of the certificate.
- `id` (String) The identity of the certificate, `<server>\<thumbprint>`.
- `issuer` (String) The issuer of the certificate.
- `not_after` (String) The end of the validity period, in UTC (RFC 3339).
- `not_before` (String) The start of the validity period, in UTC (RFC 3339).
- `private_key_exportable` (Boolean) Whether the private key can be exported from the server.
- `self_signed` (Boolean) Whether the certificate is self-signed.
- `services` (List of String) The services the certificate is enabled for, for example `IIS` and `SMTP`. Empty when it has none.
- `status` (String) The status Exchange reports, for example `Valid`, `Invalid` or `RevocationCheckFailure`.
- `subject` (String) The subject of the certificate, for example `CN=mail.contoso.com`.

## Permissions

The provider's account needs `Get-ExchangeCertificate`, from the **Exchange Server Certificates** management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
