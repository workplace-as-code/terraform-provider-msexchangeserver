# msexchangeserver_accepted_domain (Data Source)

Reads one accepted domain by name, without managing it, and fails when it does not exist. Use it to reference a domain managed elsewhere; the `msexchangeserver_accepted_domain` resource manages its settings. To read every domain, use `msexchangeserver_accepted_domains`.

## Example Usage

```terraform
data "msexchangeserver_accepted_domain" "primary" {
  name = "contoso.com"
}

output "primary_domain_type" {
  description = "Type of the contoso.com accepted domain: Authoritative, InternalRelay or ExternalRelay."
  value       = data.msexchangeserver_accepted_domain.primary.domain_type
}
```

## Schema

### Required

- `name` (String) The name of the accepted domain entry to look up.

### Read-Only

- `default` (Boolean) Whether this is the default accepted domain for the organization.
- `domain_name` (String) The SMTP domain (e.g. `contoso.com`).
- `domain_type` (String) How Exchange handles mail for this domain: `Authoritative`, `InternalRelay`, or `ExternalRelay` (Exchange Server only).
- `id` (String) The unique identifier of the accepted domain.
- `match_sub_domains` (Boolean) Whether settings apply to all subdomains.

## Permissions

The provider's account needs the **Remote and Accepted Domains** management role, which the **Organization Management** role group includes. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
