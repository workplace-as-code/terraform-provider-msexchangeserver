# msexchangeserver_retention_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_retention_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/retention_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_retention_policy" "this" {
  name = "Default MRM Policy"
}

output "retention_policy_tag_links" {
  description = "Tags of the default retention policy."
  value       = data.msexchangeserver_retention_policy.this.retention_policy_tag_links
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `id` (String) The unique identifier of the retention policy.
- `is_default` (Boolean) Whether this is the default retention policy applied to new mailboxes (read-only).
- `is_default_arbitration_mailbox` (Boolean) Whether this is the default retention policy for arbitration mailboxes (read-only).
- `retention_policy_tag_links` (Set of String) Names of the retention policy tags linked to this policy.

## Permissions

The provider's account needs the retention policy cmdlets of the **Retention Management** management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only these cmdlets. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
