# msexchangeserver_frontend_transport_service (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_frontend_transport_service`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/frontend_transport_service) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_frontend_transport_service" "ex01" {
  name = "EX01"
}

output "ex01_frontend_receive_log_path" {
  description = "Folder of the Front End Transport receive protocol logs of EX01."
  value       = data.msexchangeserver_frontend_transport_service.ex01.receive_protocol_log_path
}
```

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `connectivity_log_enabled` (Boolean) Record connectivity logs (outgoing connections).
- `connectivity_log_max_age_days` (Number) Days after which log files are removed. `0` means no age limit.
- `connectivity_log_max_directory_size_mb` (Number) Largest size, in megabytes, of the connectivity log folder. `0` means unlimited.
- `connectivity_log_max_file_size_mb` (Number) Largest size, in megabytes, of a connectivity log file. `0` means unlimited.
- `connectivity_log_path` (String) Folder of the connectivity logs.
- `id` (String) The object name (same as `name`).
- `intra_org_connector_protocol_logging_level` (String) Protocol logging of the connector that sends mail inside the organization, written to the folder of the Send connectors. `Verbose` by default. Valid values: `None`, `Verbose` (case-insensitive).
- `receive_protocol_log_max_age_days` (Number) Days after which log files are removed. `0` means no age limit.
- `receive_protocol_log_max_directory_size_mb` (Number) Largest size, in megabytes, of the folder of the protocol logs of the Receive connectors. `0` means unlimited.
- `receive_protocol_log_max_file_size_mb` (Number) Largest size, in megabytes, of a protocol log file of the Receive connectors. `0` means unlimited.
- `receive_protocol_log_path` (String) Folder of the protocol logs of the Receive connectors.
- `send_protocol_log_max_age_days` (Number) Days after which log files are removed. `0` means no age limit.
- `send_protocol_log_max_directory_size_mb` (Number) Largest size, in megabytes, of the folder of the protocol logs of the Send connectors. `0` means unlimited.
- `send_protocol_log_max_file_size_mb` (Number) Largest size, in megabytes, of a protocol log file of the Send connectors. `0` means unlimited.
- `send_protocol_log_path` (String) Folder of the protocol logs of the Send connectors.

## Permissions

The provider's account needs `Get-FrontendTransportService` and `Set-FrontendTransportService`, and `Get-ExchangeServer`, from the **Exchange Servers** management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only these cmdlets and those of the Transport service: the built-in role can also change every server setting. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
