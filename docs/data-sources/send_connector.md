# msexchangeserver_send_connector (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_send_connector`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/send_connector) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_send_connector" "this" {
  name = "To internet via gateways"
}

output "address_spaces" {
  description = "Domains routed through the connector."
  value       = data.msexchangeserver_send_connector.this.address_spaces
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `address_spaces` (Set of String) Domains the connector routes mail to, as `contoso.com` or `contoso.com;10` with a cost (1 by default). `*` routes all external mail; `*.contoso.com` includes the subdomains.
- `comment` (String) Free text about the connector.
- `dns_routing_enabled` (Boolean) Route mail with DNS MX records instead of smart hosts.
- `enabled` (Boolean) Whether the connector is used.
- `fqdn` (String) Name the servers give in the HELO or EHLO command. Empty uses each server's FQDN.
- `frontend_proxy_enabled` (Boolean) Send outgoing mail through the Front End Transport service.
- `id` (String) The object name (same as `name`).
- `max_message_size_mb` (Number) Largest message, in megabytes, the connector sends. `0` means unlimited.
- `port` (Number) TCP port of the destination.
- `protocol_logging_level` (String) SMTP protocol logging. Valid values: `None`, `Verbose` (case-insensitive).
- `require_tls` (Boolean) Require TLS: mail waits in the queue when the destination does not offer it.
- `smart_host_auth_mechanism` (String) Authentication with the smart hosts. `BasicAuth` and `BasicAuthRequireTLS` need a user name and password, which the provider does not manage: set them with `Set-SendConnector -AuthenticationCredential` first. `ExchangeServer` is used by the connectors of EdgeSync. Valid values: `None`, `BasicAuth`, `BasicAuthRequireTLS`, `ExchangeServer`, `ExternalAuthoritative` (case-insensitive).
- `smart_hosts` (Set of String) Host names or IP addresses mail is sent to. Leave empty and set `dns_routing_enabled` to route with DNS MX records.
- `source_transport_servers` (Set of String) Mailbox or Edge servers that send mail through the connector.
- `tls_auth_level` (String) Check made on the certificate of the destination when `require_tls` is `true`. Valid values: `EncryptionOnly`, `CertificateValidation`, `DomainValidation` (case-insensitive).
- `tls_certificate_name` (String) Certificate the servers present, as `<I>issuer<S>subject`.
- `tls_domain` (String) Domain the certificate of the destination must match with `DomainValidation`.

## Permissions

The provider's account needs the **Send Connectors** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) and the **Organization Management** role group include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
