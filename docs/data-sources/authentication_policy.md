# msexchangeserver_authentication_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_authentication_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/authentication_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_authentication_policy" "block_basic" {
  name = "Block Basic"
}

output "basic_pop_blocked" {
  description = "Whether the policy blocks Basic authentication for POP3."
  value       = data.msexchangeserver_authentication_policy.block_basic.block_legacy_auth_pop
}
```

- `name` (String) Identifies the object to read.

### Read-Only

- `block_legacy_auth_activesync` (Boolean) Block Basic authentication for Exchange ActiveSync.
- `block_legacy_auth_autodiscover` (Boolean) Block Basic authentication for Autodiscover.
- `block_legacy_auth_imap` (Boolean) Block Basic authentication for IMAP4.
- `block_legacy_auth_mapi` (Boolean) Block Basic authentication for MAPI over HTTP.
- `block_legacy_auth_offline_address_book` (Boolean) Block Basic authentication for offline address book downloads.
- `block_legacy_auth_pop` (Boolean) Block Basic authentication for POP3.
- `block_legacy_auth_rpc` (Boolean) Block Basic authentication for Outlook Anywhere (RPC over HTTP).
- `block_legacy_auth_web_services` (Boolean) Block Basic authentication for Exchange Web Services.
- `block_modern_auth_activesync` (Boolean) Block modern authentication (OAuth) for Exchange ActiveSync.
- `block_modern_auth_autodiscover` (Boolean) Block modern authentication (OAuth) for Autodiscover.
- `block_modern_auth_imap` (Boolean) Block modern authentication (OAuth) for IMAP4.
- `block_modern_auth_mapi` (Boolean) Block modern authentication (OAuth) for MAPI over HTTP.
- `block_modern_auth_offline_address_book` (Boolean) Block modern authentication (OAuth) for offline address book downloads.
- `block_modern_auth_pop` (Boolean) Block modern authentication (OAuth) for POP3.
- `block_modern_auth_rpc` (Boolean) Block modern authentication (OAuth) for Outlook Anywhere (RPC over HTTP).
- `block_modern_auth_web_services` (Boolean) Block modern authentication (OAuth) for Exchange Web Services.
- `id` (String) The object name (same as `name`).

## Permissions

The provider's account needs the **Organization Configuration** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) and the **Organization Management** role group include. The read account gets `Get-AuthenticationPolicy` from the read role group of the same script: View-Only Organization Management does not contain it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
