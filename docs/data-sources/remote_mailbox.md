# msexchangeserver_remote_mailbox (Data Source)

Reads a remote mailbox (`Get-RemoteMailbox`): the on-premises object of a mailbox hosted in Exchange Online, in a hybrid organization. Remote mailboxes are read-only from this provider.

## Example Usage

```terraform
data "msexchangeserver_remote_mailbox" "helpdesk" {
  identity = "helpdesk@contoso.com"
}

output "helpdesk_routing_address" {
  description = "Where on-premises mail to the helpdesk is routed in Exchange Online."
  value       = data.msexchangeserver_remote_mailbox.helpdesk.remote_routing_address
}
```

## Schema

### Required

- `identity` (String) The remote mailbox to look up: UPN, email address, alias or distinguished name.

### Read-Only

- `alias` (String) The alias.
- `display_name` (String) The display name.
- `email_address_policy_enabled` (Boolean) Whether email address policies set the addresses of the remote mailbox.
- `email_addresses` (List of String) All SMTP proxy addresses, without the `smtp:` prefix.
- `exchange_guid` (String) The Exchange GUID, which must match the one of the mailbox in Exchange Online.
- `hidden_from_address_lists_enabled` (Boolean) Whether the remote mailbox is hidden from the address lists.
- `id` (String) The Exchange identity of the remote mailbox (same as `identity`).
- `primary_smtp_address` (String) The primary SMTP address.
- `recipient_type_details` (String) The remote mailbox type: `RemoteUserMailbox`, `RemoteSharedMailbox`, `RemoteRoomMailbox` or `RemoteEquipmentMailbox`.
- `remote_routing_address` (String) The address mail is routed to in Exchange Online, usually `<alias>@<tenant>.mail.onmicrosoft.com`, without the `SMTP:` prefix.
- `user_principal_name` (String) The user principal name.

## Permissions

The provider's account needs `Get-RemoteMailbox`, from the read-only **View-Only Recipients** management role, which **View-Only Organization Management** includes. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants it through a custom role that holds only this cmdlet. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
