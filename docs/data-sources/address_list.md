# msexchangeserver_address_list (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_address_list`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/address_list) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_address_list" "rooms" {
  name = "All Rooms"
}

output "rooms_filter" {
  description = "Filter of the built-in room list."
  value       = data.msexchangeserver_address_list.rooms.recipient_filter
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `container` (String) Name of the parent address list, for a list nested in another one. Empty for a top-level list. Changing it creates a new list.
- `display_name` (String) The name shown in Outlook. Defaults to `name`.
- `id` (String) The object name (same as `name`).
- `recipient_container` (String) Organizational unit the filter applies to, as a canonical name (`contoso.com/Paris`). `""` applies it to the whole organization. Only recipients in this unit can be in the list.
- `recipient_filter` (String) OPATH filter of the recipients in the list, for example `Company -eq 'Contoso' -and RecipientType -eq 'UserMailbox'`. Exchange rewrites it with parentheses: the configured text is kept as long as Exchange returns the text it wrote.

## Permissions

The provider's account needs the **Address Lists** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) and the **Organization Management** role group include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
