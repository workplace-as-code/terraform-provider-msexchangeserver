# msexchangeserver_imap_settings (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_imap_settings`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/imap_settings) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_imap_settings" "ex01" {
  name = "EX01"
}

output "ex01_imap_login_type" {
  description = "Sign-in method of IMAP4 on EX01."
  value       = data.msexchangeserver_imap_settings.ex01.login_type
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `external_connection_settings` (Set of String) Host names, ports and encryption shown to clients on the internet, as `mail.contoso.com:995:SSL`.
- `id` (String) The object name (same as `name`).
- `internal_connection_settings` (Set of String) Host names, ports and encryption shown to clients inside the network, as `mail.contoso.com:995:SSL`.
- `login_type` (String) Sign-in method. `SecureLogin`, the Exchange default, accepts a clear-text password only on an encrypted connection. Valid values: `PlainTextLogin`, `PlainTextAuthentication`, `SecureLogin` (case-insensitive).
- `max_connection_from_single_ip` (Number) Largest number of connections from one IP address.
- `max_connections` (Number) Largest number of connections to the server.
- `max_connections_per_user` (Number) Largest number of connections of one user.
- `ssl_bindings` (Set of String) Addresses and ports of the SSL connections, as `0.0.0.0:995`.
- `unencrypted_or_tls_bindings` (Set of String) Addresses and ports of the unencrypted and TLS (STARTTLS) connections, as `0.0.0.0:110`.
- `x509_certificate_name` (String) Host name of the certificate used for SSL and TLS, such as `mail.contoso.com`. Binding a certificate to the service with `msexchangeserver_exchange_certificate_services` also sets it.

## Permissions

The provider's account needs `Get-ImapSettings` and `Set-ImapSettings`, from the **POP3 And IMAP4 Protocols** management role, and `Get-ExchangeServer`. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
