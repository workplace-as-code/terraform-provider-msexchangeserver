# msexchangeserver_client_access_service (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_client_access_service`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/client_access_service) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_client_access_service" "ex01" {
  name = "EX01"
}

output "autodiscover_service_internal_uri" {
  description = "Autodiscover URL that EX01 publishes in Active Directory."
  value       = data.msexchangeserver_client_access_service.ex01.autodiscover_service_internal_uri
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `autodiscover_service_internal_uri` (String) Autodiscover URL published in Active Directory (service connection point), for example `https://autodiscover.contoso.com/Autodiscover/Autodiscover.xml`. An empty string clears it.
- `id` (String) The object name (same as `name`).

## Permissions

The provider's account needs `Get-ClientAccessService` and `Set-ClientAccessService`, from the **Exchange Servers** management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only these cmdlets: the built-in role can also change every server setting. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
