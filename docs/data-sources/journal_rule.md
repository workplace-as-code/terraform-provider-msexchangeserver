# msexchangeserver_journal_rule (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeserver_journal_rule`](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/resources/journal_rule) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeserver_journal_rule" "all" {
  name = "Journal all mail"
}

output "journal_address" {
  description = "Address that receives the journal reports of the rule."
  value       = data.msexchangeserver_journal_rule.all.journal_email_address
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `enabled` (Boolean) Whether the rule is enabled. A rule created disabled never journals a message.
- `id` (String) The object name (same as `name`).
- `journal_email_address` (String) Address that receives the journal reports: a journaling mailbox or an archiving system.
- `recipient` (String) SMTP address of the mailbox, contact or group whose messages are journaled. `""` journals every recipient.
- `scope` (String) Messages the rule journals: all of them, internal ones or external ones. Valid values: `Global`, `Internal`, `External` (case-insensitive).

## Permissions

The provider's account needs the **Journaling** management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeserver/blob/main/tools/new_role_group.ps1) and the **Organization Management** role group include. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeserver/latest/docs/guides/authentication).
